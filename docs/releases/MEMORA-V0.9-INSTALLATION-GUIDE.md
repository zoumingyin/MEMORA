## 2. 安装前准备

### 2.1 系统要求

- Windows 10 或 Windows 11，x64。
- 建议至少 200 MB 可用磁盘空间。
- 需要 Microsoft Edge WebView2 Runtime。Windows 11 通常已内置；Windows 10 如未安装，安装程序默认使用 `downloadBootstrapper` 联网获取，因此需要可用网络。
- 若使用在线 AI 模型，需要可用网络连接；本地 Ollama 等模型需要本机服务可达。

### 2.2 代码签名

当前安装包未配置代码签名。Windows SmartScreen 可能显示“未知发布者”或阻止运行。只有在确认安装包来源和 SHA-256 正确后才选择继续。

### 2.3 备份现有数据

从旧版本升级前，建议先备份：

1. 打开 MEMORA。
2. 进入“设置”。
3. 找到“数据”区域。
4. 点击“备份数据库”，选择非安装目录作为保存位置。

也可以开启“每日自动备份”。该功能在启动时复制数据库，保留最近 7 份。

手动备份时，建议同时复制：

```text
%APPDATA%\com.bianqian.desktop\bianqian.db
%APPDATA%\com.bianqian.desktop\ai-config.json
```

如果存在 `bianqian.db-wal` 或 `bianqian.db-shm`，应先关闭应用再一起复制。

## 3. 安装步骤

1. 退出正在运行的 MEMORA。关闭主窗口只会隐藏到托盘，需使用托盘菜单彻底退出。
2. 双击 `MEMORA_0.9.0_x64-setup.exe`。
3. 如出现 SmartScreen 提示，核对文件来源和 SHA-256 后再决定是否继续。
4. 选择安装目录。默认安装到 `%LOCALAPPDATA%\MEMORA`，不需要管理员权限。
5. 完成安装。
6. 安装程序会创建开始菜单快捷方式和桌面快捷方式。
7. 从开始菜单或桌面快捷方式启动 MEMORA。

### 3.1 首次启动

- 首次启动会显示启动窗口，然后进入主界面。
- 全新安装会在 `%APPDATA%\com.bianqian.desktop\bianqian.db` 创建数据库并自动执行迁移 1–9。
- 如果检测到旧版数据目录 `%APPDATA%\com.bianqian.app`，且新数据库不存在，应用会尝试复制旧数据库、AI 配置、免费模型缓存和 WebView 数据。
- 首次启动可能需要数秒完成数据库初始化。

### 3.2 关闭与托盘

主窗口右上角的关闭操作默认是“隐藏到托盘”，不是退出进程。

- 需要彻底退出时，使用托盘菜单中的退出命令。
- 关闭窗口后进程仍在运行，应用继续驻留托盘。
- 提醒到点后的系统通知行为未在本轮做人工到点验证，正式发布前应补测。

## 4. 数据位置

| 内容 | 默认位置 |
| --- | --- |
| 主数据库 | `%APPDATA%\com.bianqian.desktop\bianqian.db` |
| SQLite WAL / SHM | 与数据库同目录 |
| AI 配置 | `%APPDATA%\com.bianqian.desktop\ai-config.json` |
| 免费模型缓存 | 应用数据目录下的免费模型缓存文件 |
| WebView 数据 | `%LOCALAPPDATA%\com.bianqian.desktop\EBWebView` |
| 手动备份 | 用户在“备份数据库”中选择的位置 |
| 自动备份 | 用户在“自动备份”设置中指定的位置 |
| 程序文件 | 安装目录，仅包含应用与卸载程序 |

程序文件与用户数据分离。卸载程序默认不会把数据库放进安装目录，也不会在安装目录保存用户内容。

## 5. 安装后检查

建议按以下顺序检查：

1. 应用能正常启动，主界面和启动页显示正常。
2. 新建一条便签，输入标题和正文，退出详情后列表可见。
3. 新建一条待办，添加子任务并勾选，进度正确变化。
4. 新建一条提醒，确认默认闹钟存在，再添加一个闹钟。
5. 搜索标题关键词，确认命中；搜索不存在的词，确认无结果。
6. 切换分类筛选，确认只显示对应类型。
7. 删除一条便签到废纸篓，再从废纸篓恢复。
8. 打开设置，切换浅色/深色/跟随系统，调整透明度。
9. 关闭主窗口，确认进程仍在托盘运行。
10. 重启应用，确认刚才的数据仍在。
11. 如已配置 AI，打开助手发送一条只读查询，确认能返回结果。
12. 打开执行历史，确认列表和详情可显示。
13. 设置一个 1 分钟后的提醒，确认系统通知实际弹出。
14. 用鼠标拖动窗口到屏幕边缘，确认吸附行为。
15. 如启用开机自启和全局快捷键，重启系统后复测。

## 6. AI 配置

- 已有 AI 配置在覆盖安装后保留。
- 安装程序不会自动切换用户当前模型。
- 全新安装后可在设置中配置自己的模型服务。
- 本地模型需要本机服务先启动；例如 Ollama 默认地址为 `http://127.0.0.1:11434`。
- 本轮已使用当前 Doubao 配置完成真实模型 A–L 验收，但供应商可用性仍受网络和限流影响。

## 7. 卸载

### 7.1 交互式卸载

1. 退出 MEMORA。
2. 打开“设置 > 应用 > 已安装的应用”，找到 MEMORA。
3. 选择卸载。
4. 注意“删除应用数据”选项：
   - **不勾选**：保留数据库、AI 配置和执行历史，重新安装后可继续使用。
   - **勾选**：删除应用数据。该操作不可恢复，除非已有备份。

### 7.2 静默卸载

静默卸载默认保留应用数据。静默卸载适合自动化和升级维护，但不会给用户二次确认机会。

### 7.3 完全清理

如需彻底移除：

1. 先备份需要保留的数据。
2. 卸载应用。
3. 手动删除 `%APPDATA%\com.bianqian.desktop`。
4. 如存在，删除 `%LOCALAPPDATA%\com.bianqian.desktop` 下的 WebView 数据。

不要删除 `%APPDATA%\com.bianqian.app`，除非确认它是旧版遗留数据且不再需要。

## 8. 常见问题

### 8.1 安装时提示未知发布者

当前安装包未签名。核对 SHA-256 和来源后再决定是否继续。

### 8.2 启动后空白或无法加载

- 确认 WebView2 Runtime 已安装。
- 尝试彻底退出托盘进程后重新启动。
- 检查安装目录是否完整，至少应存在 `bianqian.exe` 和 `uninstall.exe`。

### 8.3 关闭窗口后进程还在

这是托盘常驻设计。使用托盘菜单退出。

### 8.4 数据看起来没有升级

- 确认启动的是新安装的应用，而不是旧目录中的旧程序。
- 检查 `%APPDATA%\com.bianqian.desktop\bianqian.db` 是否存在。
- 如首次启动前已存在新数据库，旧目录数据不会自动覆盖它。

### 8.5 恢复备份后没有变化

“恢复数据库”会在下次启动时生效。恢复后请彻底退出应用并重新启动。

### 8.6 迁移失败后无法启动

当前版本在迁移冲突时会 fail-fast 退出，不会自动修复数据库。数据通常仍保留在原位置。

处理方式：

1. 不要删除数据库。
2. 将 `%APPDATA%\com.bianqian.desktop\bianqian.db` 复制到安全位置。
3. 使用之前的手动备份或自动备份，通过“恢复数据库”流程恢复。
4. 如无法进入应用，可在应用关闭状态下用备份文件覆盖 `bianqian.db`，再启动。
5. 保留原始文件，便于后续排查。

## 9. 安全提示

- 安装包内含构建期内置的模型访问密钥，不能把安装包视为不含秘密的普通文件。
- 不要从不可信渠道下载安装包。
- 不要把 `ai-config.json` 或数据库备份发送给不可信第三方；其中可能包含个人便签内容和模型配置。
- 卸载前先备份需要保留的数据。
